# Website font

`InterVariable.woff2` is the unmodified Inter 4.1 variable font from
[the official Inter distribution](https://rsms.me/inter/font-files/InterVariable.woff2?v=4.1).
It is distributed under the accompanying [SIL Open Font License](./Inter-LICENSE.txt).

The public website loads it as `MarkFlowy Sans` to keep font weights and optical
sizing consistent without relying on a third-party font request. Chinese text
uses the system Chinese font. The font is preloaded only on public website routes.
