# 片段库

设置 → 片段库用于管理本机全局的 Math、Mermaid、Code 源码片段。编辑器菜单中的“管理片段”可以直接打开对应分类。

| 类型 | 内置示例 | 填写内容 |
| --- | --- | --- |
| Math | 分式 | 公式源码，不含外层 `$$`。 |
| Mermaid | 流程图 | 图表源码，不含 Markdown 代码围栏。 |
| Code | JSON | 代码源码，不含围栏；语言单独选择。 |

## 创建和管理

内置片段可隐藏、恢复或复制为自定义片段。自定义片段支持名称搜索、新建、编辑、复制和删除。保存会保留源码的缩进、Tab 和首尾换行；`${…}` 按文字处理。

修改先保留为草稿，点击“保存”后才写入片段库。离开条目、切换设置页或关闭管理窗口时，可以保存、放弃或取消。点击“预览”可查看片段效果；源码修改后需要重新预览，预览失败不阻止保存。

## 插入文档

在所见即所得编辑器中输入 `/`，用鼠标或上下方向键选中 Math、Mermaid 或 Code 时，会展开片段子菜单，键盘焦点仍留在当前分类。直接按 Enter 会插入空白块，并自动聚焦源码编辑区；按右方向键后才能用上下方向键选择子菜单条目，也可以直接点击片段插入。左方向键返回分类，Escape 逐级关闭，取消和管理片段均保留 `/`。块工具栏右侧的片段按钮会替换先前的源码选区，或在光标处插入；没有有效位置时在源码末尾插入。已有代码块保留语言，新建代码块采用片段语言。一次插入可一次撤销。

## 保存与多窗口使用

片段库保存在应用数据目录的 `snippets.json`，可在不同工作区中复用。保存后，其他窗口也会更新。如果同一片段已被另一个窗口修改，当前草稿会保留并提示冲突。先复制需要保留的内容，再放弃草稿并重新打开条目，载入最新版本后继续编辑。
