# Button

Use the shared `components/button` primitive for new code, with `variant`, `size`, native button props, and `className`. Buttons default to `type="button"`; forms must opt in to `type="submit"`. Give icon-only buttons an accessible name.

The root-level `Button` is a compatibility adapter for existing consumers. Consult its exported props when migrating legacy loading or appearance options. See the [migration guide](../../docs/migration.md).
